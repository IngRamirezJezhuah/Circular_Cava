# Circular_Cava

> [!important]
> Haz visto los vidieso dupstep de musica y el fondo el espectro de audio que tiene este bueno pues  yo hice uno similar, a falta de encontrar algunos probe por intentar mi version

El proyecto lo que es es una adicion visual con un espectro de audio con forma esferica que se ve muy chulo en tu pantalla, en futuras actualizaciones este se convertira en una fusion entre visual funcional agregando una capa que te permite usarlo como reproductor multimedia
## Como descargarlo

> [!tip]
> Ve al boton verde que dice `code` y le das a copiar repo via http
abre tu terminal de git y ejecut el siguiente comando
`git clone https://github.com/IngRamirezJezhuah/Circular_Cava.git`
eso copiara el programa en la carpeta con el contenido

La aplicacion esta basada en Rust + Eww
se requieren dependencias por lo que ejecuta los archivos de dependencias
```
chmod +x ./dependencias.sh
./dependencias
```
 una vez instaladas las dependencias para abrirlo usa el archivo launch.sh
```
chmod +x ./launch.sh
./launch.sh
```
y voila ya estaria
